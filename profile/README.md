## Quantum Chemistry group Vrije Universiteit Amsterdam

### What should be put here:

- Small coding projects that are not part of a large developments.
- Summary files generated by agents that you want to share in the group.

### What should NOT be put here:

- Large coding projects with external collaborators that have their own git repo (like AMS, DIRAC, ROSE, ..).
- Data sets that we want to make available to the public (there are better places for that).
